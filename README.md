# Cognitive Condensate Theory (CCT)

**A speculative conceptual framework and historical OMPU archive.**

> [!IMPORTANT]
> CCT is exploratory work, not an established scientific theory. The equations,
> metrics, analogies, predictions, psychological examples, and AI claims in this
> repository have not been validated as a unified framework. Nothing here is
> medical, psychological, legal, financial, or safety advice.

## Reading rule

Treat every item as one of four things: a hypothesis, a prototype, a historical
record, or a creative artifact. A file becomes empirical evidence only when it
links to a recoverable source and states a method that can be checked.

Old files remain useful as provenance and failure history. Newer files may
correct, narrow, or contradict them. Repository location alone does not confer
truth, endorsement, authorship, agency, or operational authority.
